Bloque 2 · El portfolio

De Flask y Webpack a React, TypeScript y RAG

Mis primeros proyectos los construí con Flask y SQLAlchemy en el backend, y React con Webpack — sin TypeScript — en el frontend. Fue la base de aprendizaje. Desde ahí me especialicé, de forma autodidacta, en el stack que hoy usan de verdad los equipos de producto: React, TypeScript, FastAPI y sistemas de IA generativa con recuperación aumentada por generación (RAG).

No son ejercicios de clase: son proyectos completos, cada uno con su propio backend y frontend corriendo, integración continua en GitHub Actions y un historial de control de versiones cuidado.

4 proyectos completos, con CI real, publicados en GitHub
  • 01 personal-rag-assistant
    Asistente de IA con RAG: embeddings locales, ChromaDB y generación con Claude/Gemini.
  • 02 personal-rag-assistant-ui
    Frontend React + TypeScript del asistente RAG — pantallas de Documentos y Preguntas.
  • 03 expense-api
    Backend FastAPI de gestión de gastos: JWT, SQLAlchemy 2.0, Alembic, CI en GitHub Actions.
  • 04 expense-tracker-ui
    Frontend React + TypeScript que consume expense-api con un cliente tipado generado desde su OpenAPI.

El CV se centra en el stack objetivo: React, TypeScript, FastAPI y RAG. Quedan fuera, a propósito, herramientas y tecnologías que he tocado en otras etapas pero que no pesan hoy para ese objetivo — por ejemplo PHP/WordPress o Kotlin.
